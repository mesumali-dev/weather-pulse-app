# ☀️ WeatherPulse | Real-Time Atmospheric Forecast Application

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue?style=flat-square&logo=python)](https://python.org)
[![Streamlit](https://img.shields.io/badge/Streamlit-Dashboard-FF4B4B?style=flat-square&logo=streamlit)](https://streamlit.io/)
[![OpenWeather API](https://img.shields.io/badge/API-OpenWeatherMap-orange?style=flat-square)](https://openweathermap.org/)

> Clean meteorological forecasting application fetching live weather conditions, humidity indices, wind velocity, and ambient temperatures worldwide.

---

## 🌤️ Weather Metrics Displayed

- **Live Temperature:** Current temperature with 'Feels Like' thermodynamic calculations.
- **Atmospheric Conditions:** Humidity percentages, wind speeds, and barometric pressure.
- **Weather Status Visuals:** Dynamic meteorological iconography corresponding to sunny, overcast, rainy, or snowy states.
- **Global Search:** Immediate lookup for thousands of global cities.

---

## 🚀 How to Run

```bash
git clone https://github.com/mesumali-dev/weather-pulse-app.git
cd weather-pulse-app

pip install streamlit requests
streamlit run app.py
```
